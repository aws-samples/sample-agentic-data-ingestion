# Support

## This project is sample code, provided AS-IS

Agentic Data Ingestion is published as a reference architecture for reading and
adapting. It is **not** an AWS product or service.

- There is **no AWS Support** coverage for this repository. AWS Support cannot
  take cases about it, and it is out of scope for enterprise support agreements.
- There is **no service-level agreement**, no uptime commitment, and no
  guarantee of backwards compatibility between commits.
- There is **no committed release schedule** and no guarantee that issues or
  pull requests will be addressed within any particular timeframe.

## Getting help

| What you need | Where to go |
|---|---|
| A bug in this sample | Open a GitHub issue in this repository |
| A question about adapting it | Open a GitHub issue with the `question` label |
| A security vulnerability | See [SECURITY.md](SECURITY.md) — **not** a public issue |
| Help with an underlying AWS service | [AWS Support](https://aws.amazon.com/support/) or [AWS re:Post](https://repost.aws/) |
| Cost or architecture guidance | Your AWS account team |

Before opening an issue, please check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md),
which covers the failure modes encountered most often during development.

## Response times

Issues and pull requests are handled on a best-effort basis. There is no
committed response time.
