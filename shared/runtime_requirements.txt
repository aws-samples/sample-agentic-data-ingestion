# ── OpenTelemetry: pinned to match the ADOT managed layer ────────────────────
# DO NOT unpin these, and do not bump them without checking the ADOT layer.
#
# These are transitive dependencies of strands-agents, which asks only for
# `opentelemetry-api>=1.30.0,<2.0.0`. Left unpinned, the layer bundling's
# `pip install --upgrade` resolved them to 1.44.0, and that silently broke
# OpenTelemetry instrumentation on every Lambda that also has the ADOT layer.
#
# The mechanism is a layer merge, not a Python resolution failure. Lambda
# unpacks every layer into one `/opt/python`, so two OpenTelemetry copies land
# on top of each other:
#
#   - ADOT (`aws-otel-python-arm64-ver-1-32-0`) ships api 1.32.0/1.33.1, which
#     include `opentelemetry/_events/` and define
#     `_OTEL_PYTHON_EVENT_LOGGER_PROVIDER` in `environment_variables`.
#   - api 1.44.0 removed BOTH: no `_events/` package, and no such constant.
#
# So 1.44.0 overwrote `environment_variables/__init__.py` while ADOT's
# `_events/` survived — nothing in 1.44.0 replaces a package it no longer has.
# ADOT's own `instrumentation/botocore` then imports `_events`, which imports
# the constant that is no longer there:
#
#   ImportError: cannot import name '_OTEL_PYTHON_EVENT_LOGGER_PROVIDER'
#     from 'opentelemetry.environment_variables'
#
# It is caught, so the handler still runs and the invocation still returns 200 —
# which is why this sat unnoticed. What is lost is the instrumentation: the
# TracerProvider comes up degraded ("TracerProvider was missing `force_flush`").
#
# 1.33.1 is the higher of the two versions ADOT ships, so pinning here can only
# match ADOT or replace it with an equally self-consistent tree — never
# downgrade it. It also satisfies strands-agents' own floor of >=1.30.0.
#
# Not solvable by dropping OpenTelemetry from this manifest instead: some
# functions (`schema_extract`) deliberately carry NO ADOT layer for size
# reasons, and for those this manifest is the only source of OpenTelemetry at
# all, so removing it would make `strands` unimportable there.
opentelemetry-api==1.45.1
opentelemetry-sdk==1.33.1
